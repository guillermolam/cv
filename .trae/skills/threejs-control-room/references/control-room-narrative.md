# Control Room Narrative (3D Layer)

The Control Room metaphor must remain recruiter-first and content-first.

## Recruiter-First Storytelling
- 3D supports the narrative; it never replaces the copy or proof links.
- The first screen must work with canvas removed.
- The 3D layer should reinforce credibility, not novelty.

## Telemetry Concepts
Allowed metaphors:
- topology nodes and edges
- flows/packets as subtle motion cues
- grid/field as “systems” context

Avoid:
- dashboards and metric tiles as primary UI
- HUD frames, heavy reticles, cyberpunk aesthetics

## Infrastructure Metaphors
- Nodes represent “systems/stations”, not menu items.
- Highlights indicate focus, not required navigation.

## Visual Hierarchy
Order:
1) HTML headline and CTAs
2) Recruiter briefing / proof index
3) 3D ambience and accents

## Attention Guidance
- Use motion sparingly.
- Use contrast and scale carefully; never outshine the content layer.
