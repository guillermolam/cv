# Control Room Narrative

The portfolio represents a cloud operations control room.

Every visual element should reinforce:

- observability
- cloud operations
- platform engineering
- security
- distributed systems

Avoid:

- generic SaaS designs
- startup landing page clichés
- decorative dashboards
- visual effects without narrative purpose

Every section should support the control room story.
