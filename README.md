# Astro Portfolio (Static)

Modern Astro + TypeScript portfolio scaffold, ready for Three.js work later (not included yet).

The original repository README content is preserved at docs/archive/original-readme.md.

## Stack

- Astro (static output)
- TypeScript (strict)
- Prettier (formatting)
- Vitest (unit tests)
- Playwright (end-to-end tests)

## Commands

Install:

```bash
pnpm install
```

Dev server:

```bash
pnpm dev
```

Type check:

```bash
pnpm check
```

Production build:

```bash
pnpm build
pnpm preview
```

Formatting:

```bash
pnpm format
pnpm format:check
```

Tests:

```bash
pnpm test
pnpm test:e2e
```
